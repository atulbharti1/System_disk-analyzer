# 🖥️ System Disk Analyzer

A Python script that scans your Mac/Windows/Linux and tells you 
exactly what is eating your storage — duplicate files, large videos, 
video editor caches, and more.

**No external libraries needed — just pure Python!**

---

## 🔍 What It Does

- 📁 Shows your **top 20 folders** by size
- 🎬 Finds all **large video files** (>100MB)
- ♻️ Detects **duplicate files** wasting space
- 🎞️ Checks **video editor folders** (VN Editor, CapCut, 
  Final Cut Pro, DaVinci Resolve)
- 📄 Saves a **full report to your Desktop** automatically

## ✅ Safe to Run
This script **only reads** your files. It never deletes, 
moves, or modifies anything.
